# HoriSub

HoriSub 从你选择的 Chrome 标签页读取声音，在设备上生成原文、译文和可选的中文朗读。音频识别直接使用可播放的音轨，适用于缺少 CC 的视频。默认模式使用本机 whisper.cpp 和 ONNX Runtime。浏览器本地模式可单独运行，使用随扩展打包的 Transformers.js 和 ONNX Runtime Web。已实测的站点和播放限制见[测试报告](VALIDATION.md)。

## 安装与第一次使用

1. 从 [GitHub Releases](https://github.com/hhhoratioxu/HoriSub/releases/latest) 下载扩展 ZIP，例如 `HoriSub-0.2.1.zip`。解压到保留位置。打开 `chrome://extensions`，开启开发者模式，在「加载已解压的扩展程序」中选择含 `manifest.json` 的目录。最低版本为桌面 Chrome 116。建议从扩展菜单固定 HoriSub。
2. 使用默认本机引擎时，从同一发布页另下载并解压对应的引擎 ZIP。Apple Silicon Mac 选择 `darwin-arm64`，运行 `Install.command`。Windows x64 选择 `win-x64`，运行 `Install.cmd`。安装器在当前账户注册引擎，使用时由 Chrome 自动启动。选择「浏览器本地」时可以直接进入模型准备。
3. 打开 HoriSub 设置，检查本机引擎状态。选择「本机引擎」或「浏览器本地」，再选择模型。英译简体或繁体可用默认的 Whisper 和 OPUS-MT。分别对语音和翻译卡片点击「下载 / 修复」。浏览器模式会请求 Hugging Face 及其模型文件主机权限。首次下载需要联网。缓存彼此独立。
4. 保存设置，点击「运行本地语音自检」。自检将随扩展附带的语音样本交给所选本地引擎，显示原文、译文、后端和实测处理时间。先用这一步确认准备状态。
5. 打开 YouTube 视频或正在播放的直播，在该标签页打开工具栏 HoriSub，点击「开始字幕」。双语时原文在上，译文在下。关闭弹窗可以继续播放。点击「停止字幕」会关闭捕获、识别和朗读。

macOS 引擎面向 Apple Silicon、系统 13.5 或更新版本。安装 ZIP 中的应用代码没有 Developer ID 签名或公证。Windows x64 引擎包包含运行所需的 Node、whisper.cpp、ONNX Runtime 及 JavaScript 依赖。Windows 若缺少 ONNX Runtime 所需的 VC++ 系统库，先安装微软的 [Visual C++ v14 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)，再运行安装器。参见 [实际测试报告](VALIDATION.md) 了解实机范围。

### 注册、修复与卸载

- 设置页显示实际扩展 ID。当前开发包由 `manifest.json` 的公开键确定固定 ID。Chrome 商店或自定义构建使用不同 IDs 时，将真实 ID 传给安装器，例如 `./Repair.command --extension-id <实际 ID>` 或 `Repair.cmd --extension-id <实际 ID>`。安装器写入单条精确的 `allowed_origins`。无需更改代码或注册全站来源。
- 修复注册或升级时，停止字幕后运行新引擎包的 `Repair.command` 或 `Repair.cmd`，然后在设置中点击「重新检测注册」。升级会保留模型缓存，模型卡片可重新校验并补齐文件。
- 从相应引擎包运行 `Uninstall.command` 或 `Uninstall.cmd`，选择是否删除模型。随后在 `chrome://extensions` 移除扩展，浏览器模式缓存和扩展保存的字幕记录随扩展移除。如果只想删除部分浏览器模型，可以先在模型管理中选择模型并删除。
- macOS 本机缓存位于 `~/Library/Caches/HoriSub/models`，Windows 位于 `%LOCALAPPDATA%\HoriSub\models`。浏览器缓存由 Chrome 管理，分属于每个扩展配置。

## 在播放器里使用

- 弹窗可切换原文、译文和双语，可关闭字幕层、切换已检测到的当前页面播放器，并查看独立字幕窗。通用播放器需要可访问的 HTML5 `video` 元素。整个标签页只有一条音频轨，多播放器同时发声时会混入同一轨。
- 「自动选择」会使用正在显示或可读的原生字幕。「优先原生字幕」也会尝试准备可见播放器关联的 `textTracks`。检测不到时会继续从音频识别。YouTube 的原生字幕可先通过播放器 CC 打开。直接选「音频识别」可固定来源。
- 保存运行模式、识别或翻译模型、运算后端的变更后，在下次点击「开始字幕」时使用新配置。活动会话的工具栏显示实际正在使用的模式和后端。
- 拖动位置时，先从弹窗点击「拖动位置」，然后在视频上拖动手柄。设置页可恢复默认样式，设置字号、描边、底色、位置和 0–5000 ms 的额外显示延时，并打开 Chrome 快捷键设置。默认快捷键为 Alt+Shift+S，macOS 上 Alt 对应 Option。
- 点「画中画」后，在播放器中点击「打开字幕画中画」。第二次点击提供浏览器要求的页面用户操作。Document PiP 窗口镜像视频画面，原播放器和音轨保持原位。页面环境只允许字幕时，会打开独立字幕窗。受保护媒体和不支持的跨域窗口可能无法镜像。Chrome 的普通视频 PiP 会显示视频画面，字幕层留在网页。
- 中文播报默认关闭。打开设置中的「朗读实时中文译文」，选择已安装的离线声音、音量和语速。可选择播报时降低原声，停止或跳转时会清空播报。缺少离线中文声音时，macOS 可在系统的朗读内容设置中下载，Windows 可在语言与语音设置中添加。本机引擎使用 macOS AVSpeech 或 Windows SAPI。浏览器模式使用 Chrome 报告为本地服务的系统声音。
- 在「字幕记录」内搜索、复制或导出 TXT、SRT、VTT。可选原文、译文或双语。跨跳转选择会话相对时间，或导出某一连续片段的原媒体时间。原文和译文共享片段时间。音频识别时间基于语音分段和当前媒体锚点，属于估计。显示延时不改变导出时间。
- 字幕默认保存在当前的 Chrome 会话中。用户开启历史保留后，本机保存最近 4 个会话，每会话最多 1,600 条。可以在字幕记录中清除。HoriSub 不保存原始音频，不发送遥测。
- 准备模型时会联系 Hugging Face 和承载模型文件的主机。播放时音频、识别文本和译文只在本设备处理。解除扩展的可选站点授权可以从 Chrome 的扩展详情操作。

## 语言和播放器支持

| 选项 | 原文与译文 |
| --- | --- |
| Whisper tiny / base / small Q5_1 和浏览器 Whisper tiny / base | 多语言原文，可自动检测或手动固定语言。设置页列出可选语言。 |
| 浏览器 Moonshine Tiny | 适合英文视频的轻量识别模型。选择后使用固定英语源语言。 |
| OPUS-MT，默认 | 英语 → 简体中文或繁体中文。 |
| M2M100 | 设置页所列语言之间的中文或英文翻译，包括日语和韩语。需单独下载约 640 MB。 |
| 同语种 | 保留原文，目标为中文时用 OpenCC 统一简体或繁体字形。 |
| 可见原生字幕 | 支持 TextTrack 语言元数据。网页滚动字幕缺少语言元数据时可能需要手动指定。 |

| 环境 | 适配方式 |
| --- | --- |
| YouTube 直播、点播、Shorts | 播放器容器识别和 SPA 视频切换，普通、影院、容器全屏。在站点适用性确认前以测试报告为准。 |
| YouTube、Twitch、B站嵌入 | 从设置页授权相应站点。扩展只查找 Chrome 允许访问的帧。独立标签页是跨域帧受限时的可用入口。 |
| Twitch、B站、通用 HTML5 | 优先识别已知视频容器，通用模式按可见视频大小挂载。原生视频元素全屏、受保护媒体、特殊广告播放器和跨域帧有浏览器限制。 |

## 故障排查

| 现象 | 检查 |
| --- | --- |
| 有声音，但无字幕 | 确认从播放视频的标签页打开扩展，查看是否处于加载、静音或暂停，检查两个模型是否准备。用设置页自检确认实际识别速度。若捕获因休眠、导航或 Chrome 权限变化结束，请重新点击开始。 |
| 有原文，缺少译文 | 检查目标语言、翻译模型是否已准备。日语或韩语、中文转英文等选择 M2M100。网页原生字幕缺少语言标记时手动设置源语言。 |
| 全屏时字幕消失 | 使用播放器的容器全屏按钮。直接进入视频元素的原生全屏时，Chrome 没有可渲染网页字幕的容器。可用 Document PiP 或独立字幕窗。 |
| 模型加载失败 | 点击校验或下载修复。浏览器模式可改用较小模型或 CPU。Native Messaging 注册失败时检查当前 ID，再运行修复。 |
| 画中画只有字幕 | 当前页面无法打开带视频的 Document PiP，独立字幕窗会继续显示当前会话文本。 |
| 已开启但无中文播报 | 目标需为简体或繁体。安装离线中文系统声音，回到设置刷新声音列表。性能不足时，超过播报时限的译文会跳过朗读，字幕仍按可用结果显示。 |

## 构建与测试

安装开发用 Node.js 22.12 或更新版本。运行 `npm ci`、`npm test` 和 `npm run package`。扩展构建输出在 `dist/`，ZIP 和校验和在 `release/`。引擎的固定版本、构建流程与平台依赖见 [原生构建说明](native/BUILD.md)。部署包用户只需解压安装。

- [架构与数据流](ARCHITECTURE.md)
- [许可证与模型来源](THIRD_PARTY.md)
- [实际测试及限制](VALIDATION.md)

HoriSub 本地模式无需推理账户、API Key 或任何开发工具。播放网站视频和首次下载资源仍由网络和各网站规则决定。开发工具本身的账户与额度跟安装后运行 HoriSub 无关。
